# Gerador de Gabaritos V3.3

Correção crítica:
- cada saída recebe um corredor geométrico exclusivo;
- afastamento lateral obrigatório entre corredores;
- ramais longos são acomodados em serpentina dentro do próprio corredor;
- linhas independentes não podem tocar nem cruzar;
- contatos são detectados na validação;
- somente ramal filho ligado ao pai pode compartilhar o ponto de união;
- espessura de 2 mm e regra US = 100 mm mantidas.

Substitua o index.html no GitHub Pages, confirme o commit e pressione Ctrl+F5. Para testar o novo roteamento, crie um projeto novo ou reimporte o PDF.
